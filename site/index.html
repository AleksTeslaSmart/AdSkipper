Жмёт «Пропустить» сам

Кнопка нажимается сразу, как только станет активной. Ничего трогать не нужно.

Выключает звук рекламы

Пока идёт реклама, звук выключен. Видео начинается — звук возвращается. Можно отключить в настройках.

Видит только YouTube

Работает только внутри приложения YouTube и ничего никуда не отправляет. В интернет выходит, только чтобы проверить обновления.

Как установить

Около минуты. Приложение ставится из файла, не из Google Play.

Наведите камеру телефона, чтобы скачать.

  1. Скачайте и откройте файлНажмите «Скачать APK», затем откройте AdSkipper.apk из уведомления или папки «Загрузки».
  2. Разрешите установкуТелефон спросит, можно ли ставить приложения из браузера, — разрешите. Если Play Protect предупредит, нажмите «Всё равно установить».
  3. Включите сервисОткройте AdSkipper, нажмите большую кнопку и включите AdSkipper в разделе «Специальные возможности».
  4. Если переключатель серыйНа Android 13 и новее: Настройки → Приложения → AdSkipper → ⋮ → Разрешить ограниченные настройки, затем повторите шаг 3.

Что нажимать, когда телефон спрашивает

Для приложений не из Google Play Android показывает несколько предупреждений. Это нормально — вот что нажимать.

  1. «Установка неизвестных приложений» или красное окно «Danger» (Xiaomi)
    Поставьте галочку «Я осознаю риски» и нажмите OK. Это нужно один раз — для браузера.
  2. «Настройки с ограниченным доступом»
    Нажмите OK. В AdSkipper нажмите «Снять блокировку» → ⋮ → «Разрешить настройки с ограниченным доступом».
  3. «Разрешить AdSkipper полный контроль над устройством?»
    Нажмите «Разрешить». Так AdSkipper видит экран YouTube и нажимает «Пропустить». Никакие данные никуда не отправляются.
  4. Сервис сам выключается (Xiaomi, Samsung, Huawei)
    Настройки → Приложения → AdSkipper → Батарея → «Нет ограничений».

Полезно знать

Только для Android. На iPhone такие приложения запрещены.

Рекламу без кнопки «Пропустить» нельзя пропустить, но звук у неё будет выключен.

Работает с официальным приложением YouTube, не с сайтом в браузере.

Обновления ставятся поверх старой версии: приложение само покажет кнопку «Обновить», когда выйдет новая.
